# v0.6.0

## Outcome

This release completes the assessment learning loop. A debrief no longer stops
at diagnosis. It turns each material gap into a corrective control, a practical
artefact, an uncoached replay assignment, and an observable proof condition.

## Development outcome

- Failed and unresolved critical gates are always the first remediation
  priorities.
- Weak competency criteria are added without duplicating an already-covered
  gate problem.
- Every corrective assignment includes the observed diagnosis, judgment pattern,
  corrective control, required artefact, replay assignment, evidence threshold,
  and traceable source decisions.
- The debrief states one primary learning and a four-stage closure path:
  diagnosed, control built, practice corrected, and transfer verified.
- Reading the debrief or acknowledging the lesson never closes a gap.
- Corrective artefacts are prescribed but are not semantically inspected in this
  release; replay status verifies decision patterns, not document quality.

## Corrective replays

- A participant can start a separate uncoached replay from a completed first
  attempt.
- The replay is linked through participant-visible metadata and never rewrites
  the source run, score, ledger, or debrief.
- On completion, the product compares critical gates and criterion targets with
  the source development plan.
- A successful same-scenario replay is labelled `practice corrected`, not
  `transfer verified`.
- Source attempts with linked replays cannot be deleted until their replays are
  removed, preserving comparison integrity.

## Interface

- Added a Development plan tab to the executive debrief.
- Added a premium learning summary, closure path, corrective assignment cards,
  replay comparison, and next-evidence boundary.
- Run centre entries now distinguish first attempts from practice replays and
  show the source relationship.

- Attempt relationship metadata is additive and participant-owned.
