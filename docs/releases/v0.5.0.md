# v0.5.0

## Outcome

This release turns the hosted beta into a controlled private canary and makes
the assessment intelligible without changing the frozen scenario fixtures or
first-attempt scoring path.

## Assessment clarity

- The mission briefing now explains the three result layers: participant
  competency, simulated programme health, and non-compensable critical gates.
- All seven gate expectations are visible before a run without revealing an
  option answer path.
- The debrief labels the final route as defensible, gate-blocked, or unresolved
  instead of presenting the participant's D20 selection as the outcome.
- The result distinguishes the criterion-weighted score, gate-adjusted score,
  programme-health average, failed gates, and unresolved gates.
- Every gate shows its expected control, the run-specific finding, score or
  release effect, traceable decisions, and required recovery action.
- The UI now uses the correct gate `title` field and gives unresolved and not
  applicable states distinct treatment.
- The assessment boundary is explicit: free text is stored for traceability and
  completeness, while deterministic substantive scoring follows selected
  actions and normalized evidence. The release does not claim semantic prose
  evaluation.

## Canary controls

- Sign-in and sign-up are restricted server-side to a normalized invited-email
  allowlist.
- Hosted local mode is disabled by default to prevent an authentication bypass.
- Participants can permanently delete their own local or cloud runs.
- Cloud deletion remains owner-scoped by both application filters and Supabase
  RLS.
- Canary feedback and incident links are configurable and surfaced in-product.

## Compatibility

- The scenario remains `procurement-under-pressure@0.1.0`.
- Existing encrypted cloud runs and completed exports remain readable.
- Existing projects must apply the additive owner-scoped delete-policy migration;
  no table-shape or signing-key change is required.
- Existing numeric assessment results are unchanged; v0.5 changes their
  explanation and outcome classification.
